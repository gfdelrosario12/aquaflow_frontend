## MODIFIED Requirements

### Requirement: Design tokens and dark-first application theme
The application MUST provide a unified design system defined via Flutter `AquaFlowTheme` supporting both light and dark themes, incorporating centralized color tokens, typography, component styling, and official "Aqua Flow" branding.

#### Scenario: Visual theme rendering
- **WHEN** the application is launched on a device
- **THEN** the UI is styled using centralized `AquaFlowTheme` design tokens supporting both light and dark theme configurations with modern high-contrast visual indicators for agricultural IoT telemetry.
