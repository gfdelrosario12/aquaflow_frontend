## MODIFIED Requirements

### Requirement: Design tokens and dark-first application theme
The application MUST provide a unified dark-first visual design system defined via Flutter `ThemeData` incorporating color tokens, typography, component styling, and official "Aqua Flow" branding strings.

#### Scenario: Visual theme rendering
- **WHEN** the application is launched on a device
- **THEN** the UI is styled using dark theme tokens with modern high-contrast visual indicators and displays "Aqua Flow Mobile" / "Aqua Flow" branding text.
