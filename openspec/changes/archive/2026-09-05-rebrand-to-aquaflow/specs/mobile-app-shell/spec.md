## MODIFIED Requirements

### Requirement: Application bottom navigation shell
The application MUST display a primary navigation shell titled "Aqua Flow" providing access to Home, Field, Analytics, Control, and Settings screens with "Aqua Flow Dashboard" branding headers.

#### Scenario: Switching primary navigation tabs
- **WHEN** the user taps a navigation item in the bottom bar
- **THEN** the active view transitions seamlessly to the selected screen while maintaining navigation state and displaying "Aqua Flow" header identity.
